# calc-pwa

Учебный веб-калькулятор на Node.js и Express, оформленный как PWA (Progressive Web App). Сервер отдаёт страницы и API для вычислений. Service Worker кэширует страницы, поэтому приложение открывается и считает даже без связи с сервером.

## Возможности

- Главная страница `/` с калькулятором и страница `/about` с описанием проекта.
- Вычисления на сервере через HTTP API с проверкой входных данных и ответом `400` при ошибке.
- Офлайн-режим: Service Worker хранит страницы в кэше `calc-pwa-v1`. Без сервера калькулятор считает прямо в браузере и пишет под формой «Офлайн: посчитано в браузере».
- Приложение можно установить как PWA из браузера (Chrome, Edge).

## Требования

- Node.js 18 или новее и npm.
- Браузер на движке Chromium (Chrome, Edge) для демонстрации Service Worker и установки PWA.
- Проект разрабатывался в WSL (Ubuntu). В Windows, macOS и Linux команды такие же.

Проверить версии:
```bash
node -v
npm -v
```

## Установка и запуск
```bash
cd ~/calc-pwa
npm install
npm start
```

После запуска в терминале появится строка `Сервер запущен: http://localhost:3000`. Откройте этот адрес в браузере. При работе в WSL порт пробрасывается в Windows автоматически.

Если порт 3000 занят, укажите другой:
```bash
PORT=3001 npm start
```

Чтобы остановить сервер, нажмите `Ctrl+C` в окне терминала, где он запущен.

## Маршруты

| Маршрут | Описание |
|---------|----------|
| `GET /` | Главная страница с калькулятором |
| `GET /about` | Страница «О проекте» |
| `GET /api/...` | Вычисление, ответ в формате JSON |
| любой другой | `404` с JSON `{"error": "..."}` |

Если входные данные некорректны, API отвечает кодом `400` и JSON вида `{"error": "описание ошибки"}`.

## Проверка API

Во втором окне терминала, пока сервер запущен:
```bash
# корректный запрос
curl "http://localhost:3000/api/calc?a=5&b=10&op=%2B"

# некорректный запрос, ожидается 400
curl -i "http://localhost:3000/api/calc?a=1&b=0&op=/"

# несуществующий маршрут, ожидается 404
curl -i "http://localhost:3000/nope"
```

## Демонстрация офлайн-режима

1. Запустите сервер (`npm start`) и откройте http://localhost:3000.
2. Откройте DevTools (`F12`), вкладку Application.
3. В разделе Service Workers должен быть `sw.js` со статусом «activated and is running».
4. В разделе Cache Storage → `calc-pwa-v1` видны закэшированные файлы.
5. Остановите сервер (`Ctrl+C`) или включите Offline на вкладке Network.
6. Обновите страницу. Страницы `/` и `/about` откроются из кэша, калькулятор продолжит считать, под формой появится «Офлайн: посчитано в браузере».
7. Снова запустите `npm start`, чтобы вернуться в обычный режим.
